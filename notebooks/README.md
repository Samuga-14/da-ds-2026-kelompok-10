# Notebooks

Notebook yang diwajibkan:

1. `01_eda.ipynb` — profiling, cleaning evidence, dan analisis eksploratif.
2. `02_baseline.ipynb` — baseline model dan metrik awal.
3. `03_model_experiments.ipynb` — perbandingan, tuning, dan error analysis.

Issue #15 menyediakan notebook tambahan `02_eda_survey.ipynb` untuk EDA survei kos Toba
dengan distribusi tarif, lokasi, luas kamar, fasilitas, jarak fasilitas, outlier, dan
interpretasi grafik.

Notebook harus menyebut versi dataset, seed, fitur, target, dan output artifact yang dihasilkan.
